The three examples show the three ways an animation can run: every segment on its own key press, a segment that stops half-way until the presenter goes on, and a sequence that runs on its own once started.

bubble sort, the first pass

Each key press compares the next pair and swaps it if the left value is larger. After the first pass the largest value has bubbled to the end and turns green.

a request and its reply

First key: the links appear. Second key: the request travels to the router and stops there, so we can talk about what a router does; the next key sends it on to the server. Third key: the reply travels back while the clock counts the round trip.
